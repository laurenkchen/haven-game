# HAVEN GAME!
<img width="1388" height="788" alt="Screenshot 2026-11-06 at 8 32 12 PM" src="https://github.com/user-attachments/assets/d3aebe01-f9ef-4afc-aadc-875812bf2376" />

This game was made in Godot for Haven Game Jam: a hackathon running in 200+ cities simultaneously on Nov. 14-15 (haven.hackclub.com)

* Players control a cute yellow duck character!
* Special sound effects are implemented for when the character jumps
* Custom momentum, collision, and gravity controls were implemented using Godot

To run the game locally:
1)  clone the repository
2) Open the godot file (make sure godot is installed!)
3) Press F5 or the Play icon to start playing the game
